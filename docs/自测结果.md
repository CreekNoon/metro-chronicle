## 本轮新增能力的实测证据（t14）

| 需求 | 实测结果 |

## 本轮调整：线路内固定缩放 / 0.5× 速度 / 换乘配色渐进

| 需求 | 实现 | 实测证据 |
|---|---|---|
| 一条线路运行途中保持同一缩放 | 每个事件开始前按**该线长度**取景（跨度 = 长度 × 1.18，整线落在画面内）并 snapTo 对齐；运行期间只 panTo（起点→头部中点），**不动 zoom**；换级只发生在事件之间 | t14「每条线路运行途中缩放保持不变」：逐线采样 max−min ≤ 0.001（各线 zoom 恒定），且「起点与头部始终在画面内」「中点偏移 ≤ 0.16 视口」 |
| 运行速度再降到 0.5× | STORY_TIMING 全部翻倍（单线绘制 5.6–12.8s、事件间飞行 2.7s、单站停留 3.0s、开场 2.0s、收束 3.4s），整段约 50s | t1/t2/t11 以 68s 等待完整播放通过；「跳过动画」仍可直达终态（t12 32 项） |
| 换乘站颜色渐进 | 圆环渐变由**当前已开通线路**的颜色实时计算：efreshInterchange() 在每次站点点亮/线路开通后重算，≥2 条才加渐变并升级为换乘态，1 条时移除渐变保持单色 | t15：株洲站（2/3/城际三线共站）在第 2 条线开通后为**两色**（蓝+绿），第 3 条（城际紫）接入才变**三色**；清水塘在 1 号线阶段为单色 ghost，2 号线接入后转两色换乘 |

## 上一轮修复：地图闪烁 + 节奏过快

| 问题 | 原因 | 修复 | 实测 |
|---|---|---|---|
| 地图闪烁 | ① 镜头每帧 `map.setView` 触发 `moveend`，标签避让随之**逐帧重排**；② Leaflet 自身缩放/瓦片淡入动画在快速换级时反复重绘；③ 逐帧小数级缩放导致瓦片层级来回切换 | ① 标签重排改为「去抖 200ms + 播放中跳过」；② 关闭 `zoomAnimation / fadeAnimation / markerZoomAnimation`；③ 视野改为 **GSAP ticker 平滑逼近** + **缩放只在整数层级切换**（拉远立即跟、推近带滞回）；④ 瓦片层 `keepBuffer: 6 / updateWhenZooming: false` | 一次播放的中断瓦片请求从 **100–400 次降到 10–40 次**；跟拍期「起点→头部」中点偏移 ≤ 0.10 视口，头部始终在画面内 |
| 播放速度太快 | 单条线路绘制 1.9–4.6s、事件间飞行 0.8s | 放慢节奏：单线绘制 **2.8–6.4s**、事件间飞行 **1.35s**、单站停留 **1.5s**、开场/收束各加长；整段约 25s（可随时「跳过动画」） | 全程 ≈25s，t14 采样确认镜头跟拍稳定 |

顺带修复：高德/栅格瓦片在窄屏全景时相邻站圆环相碰（移动端站点标记整体缩小一档）。

## 已知限制（如实说明）

1. **镜头缩放带来较多瓦片请求**：高德栅格瓦片按整数层级取图，连续缩放会跨层级重复取图。一次完整播放约 100–400 次 `net::ERR_ABORTED`（中止的图片请求，不产生 console 报错）；断网/栅格兜底场景无此问题。
2. **单站开通的换乘表现**：若某站被设为单独开通，但它的第二条线路尚未开通，则按单线站点（实心点）展示；等第二条线路经过时才变为多色换乘环。
3. 城际铁路走向、开通日期为**虚构演示数据**；站名与经纬度取自株洲/湘潭真实地点。
4. 无 Key 时的矢量底图（MapLibre）在跨城市大跨度跳转时，会打印 1 条第三方样式解析 warning（非 error）。
5. 窄屏（≤720px）站点过密时隐藏次要站名（终端站/换乘站保留），放大或复位视野后恢复。
6. 服务端无鉴权、无 TLS，默认仅监听 `127.0.0.1`，单实例文件存储。
