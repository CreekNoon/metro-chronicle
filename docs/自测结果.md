针对"示意图出现不该有的站点 / 线段角度不是 45°"的反馈，先做了现场核对与加固：

| 项 | 处理 | 实测 |
|---|---|---|
| 角度 | 折角路由保证每条线段都落在 8 个方向上；t28 直接解析渲染出来的 SVG d 属性逐段测角 | 株洲 25 段、湘潭 12 段、取消线路后 18 段，**最大偏差 0.00°** |
| 站点归属 | 站点只在其线路"已绘制到该站"时点亮；t28 连续 6 次审计「每个可见站是否属于已开通线路」 | 孤立站点 **0 个** |
| 切换城市 / 编辑后 | **重建时销毁旧时间轴并重新播放**（之前旧事件会拿旧 lineIndex 去点亮新城市的站 —— 这是"出现不相干站点"的隐患） | 切到湘潭后：布局 9 站、时间轴重启、无残留错站 |
| 线路多选 | 布局与渲染只处理「参与播放」的线路，不再为未选线路预留位置 | 取消城际：25 段 → 18 段，角度仍为 0° |

## 示意图二期（续）：逐帧确定性视频导出

| 项 | 做法 | 实测 |
|---|---|---|
| 时间轴 | 暂停 GSAP 时间轴，按固定步长精确 seek（Schematic.seek(t)）；**倒退时先复位站点/线路状态**，保证同一 t 一定得到同一画面 | t27：同一时刻重复渲染像素哈希完全一致；倒退后再前进也一致 |
| 渲染 | 独立 canvas 渲染器（线路三层描边按 dash 揭示、站点圆环/多色换乘、17px 站名带描边光晕、HUD 等比放大），**分辨率与屏幕无关** | t27：640×360 与 **3840×2160** 都能正常渲染 |
| 编码 | canvas.captureStream(0) + 每帧 equestFrame()，MediaRecorder 直出 **MP4/H.264**，无需 FFmpeg | t27：帧数 = 时长 × fps（120 帧 / 5s）、typ 容器正确、浏览器可解码、时长误差 < 1s |
| 产物 | 内置按钮在**示意图视图**下自动走逐帧渲染，1080p；样例 docs/samples/株洲地铁开通纪事_示意图_1080p.mp4（1920×1080 / 18s / 540 帧 / 3.1MB） | 用 CDP 下载并校验容器结构（ftyp + moov + moof/mdat + avcC） |

与"实时录制"的区别：实时录制会把浏览器的掉帧一并录进去；逐帧渲染**每帧内容严格对应时间轴时刻**，渲染一帧仅几毫秒，因此不会丢内容，且可以任意分辨率（4K）导出。

## 阶段性升级 ④：线网示意图引擎（RMP，由地理数据自动派生）

| 项 | 做法 |
|---|---|
| 数据源 | **仍是 WGS84 地理数据**（App.plan 不变）；示意图只是派生出来的"视图" |
| 八方向化 | 每条线从起点出发，把相邻站点的地理方位**吸附到 45° 的整数倍**，段长按真实距离成比例压缩 |
| 换乘对齐 | 段长 + 整线平移的**联合最小二乘拟合**（只调长度与平移，方向永远不变），把共用站拉到一起；再按"最长线优先"确定站点落点 |
| 折角路由 | 若两站连线不在 8 个方向上，插入 **45°/90° 折角**（真实地铁图的标准做法），保证**每条线段都严格落在 8 个方向上** |
| 渲染 | 纯 SVG（线路三层描边）+ DOM 站点节点（复用现有 .st 样式，换乘用多色圆环）；视口缩放用 CSS transform |
| 播放 | 复用同一套节奏（全景 ↔ 特写 ×2.15），线路用 stroke-dashoffset 逐帧揭示，站点按里程比例点亮 |
| 自动重排 | 包装 Scene.build：**任何一次编辑保存 / 切换城市 / 恢复默认之后，示意图自动重新派生** |

**实测布局质量**（株洲 4 线 12 站）：线段 25 条，**全部严格 45°/90°（最大偏差 0.00°）**；换乘站 7 个，**各线落点完全重合（偏差 0.0px）**；任意两站最小间距 **45.4px**；画布 867×754。

**验证**：t25（17 项）——八方向布局、站点数一致、间距、换乘重合、三层描边、站点 DOM、多色换乘环、标签齐全、全景≈1 倍、播放点亮、切换城市后自动重排且仍是八方向。

## 已知限制（如实说明）

1. **镜头缩放带来较多瓦片请求**：高德栅格瓦片按整数层级取图，连续缩放会跨层级重复取图。一次完整播放约 100–400 次 `net::ERR_ABORTED`（中止的图片请求，不产生 console 报错）；断网/栅格兜底场景无此问题。
2. **单站开通的换乘表现**：若某站被设为单独开通，但它的第二条线路尚未开通，则按单线站点（实心点）展示；等第二条线路经过时才变为多色换乘环。
3. 城际铁路走向、开通日期为**虚构演示数据**；站名与经纬度取自株洲/湘潭真实地点。
4. 无 Key 时的矢量底图（MapLibre）在跨城市大跨度跳转时，会打印 1 条第三方样式解析 warning（非 error）。
5. 窄屏（≤720px）站点过密时隐藏次要站名（终端站/换乘站保留），放大或复位视野后恢复。
6. 服务端无鉴权、无 TLS，默认仅监听 `127.0.0.1`，单实例文件存储。
