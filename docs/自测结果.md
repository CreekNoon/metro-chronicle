# 城市地铁线网开通纪事 · 使用说明与自测结果（v2）

> v2 相对 v1 的改动：① 内置高德 Key，默认高德底图；② 站点/线路发光更克制；③ 新增缩放控件（播放期间可缩放）与「跳过动画」；④ 支持多线路（默认 3 地铁 + 1 城际）与城际铁路特殊站标、线路多选；⑤ 增加零依赖 Node 后端（方案服务端存储、前后端联动）。

## 一、怎么用

### 方式 A：双击打开（零依赖、完全离线）

直接双击 `地铁线网开通纪事.html`。底图按「高德（内置 Key）→ OpenFreeMap 矢量 → Esri 栅格 → 本地浅灰画布」降级；方案存在浏览器 `localStorage`。断网也能完整播放。

### 方式 B：前后端一体（方案存在服务端）

```bat
node metro-chronicle/server/server.mjs            :: 默认 http://127.0.0.1:8787
:: 或指定端口： set PORT=8799 && node metro-chronicle/server/server.mjs
```

浏览器打开 `http://127.0.0.1:8787/`。此时页面启动即从 `/api/plans` 拉取方案，之后每次编辑都会写穿到服务端（`metro-chronicle/server/data/store.json`），换浏览器/换设备也能拿到同一份方案；服务端不可达时自动退回纯本地模式，界面不报错。

API：`GET /api/health`、`GET|PUT|DELETE /api/plans?city=<id>`、`GET /api/plans`、`GET|PUT /api/cities`（详见 `metro-chronicle/server/README.md`）。

### 主要交互

| 区域 | 能力 |
|---|---|
| 左上 | 时间胶囊（开通日期）+ 线路头（彩色徽章 / 线路名 / 区间 / 试运行·开通运营） |
| 左侧 | 数据面板：线路数 / 站点数 / 里程（全部由平滑曲线实测里程实时统计） |
| 右上 | 城市切换、**线路多选**（勾选参与播放的线路）、编辑线网、地图设置（高德 Key） |
| 右侧 | **缩放控件**（＋ / － / 复位视野 / 比例尺提示）；播放期间手势锁定，但按钮始终可用 |
| 左下 | 重播、**跳过动画** |
| 右下 | 版权与数据来源（随底图源变化） |
| 编辑态 | 底部工具条（线路切换 / 新建地铁·城际 / 删除本线 / 恢复默认 / 清空本线 / 完成并播放）+ 站点卡片（序号、站名、暂未开通、加入本线、前移后移删除） |

## 二、需求对应实现

1. **高德 Key 内置、默认高德**：`src/10-cities.js` 的 `AMAP_KEY = '54f4cc0397a9d44e9dd7690811f2b638'`（已用高德服务端接口验证：`status=1 / infocode=10000`）。默认直接铺高德瓦片，`datum=gcj02`，站点/线路渲染前做 WGS84→GCJ-02 投影；**编辑与持久化始终是 WGS84**。Key 仍可在「地图设置」里覆盖或清除；Key 明确无效时静默回退默认链路（矢量→栅格），网络不可达时保留高德瓦片（不误伤配置）。
2. **发光更克制**：站点 halo 44px→**26px**、模糊 4px→3px，且点亮动画收敛到 **0.09（ghost 0.035 / 换乘 0.06）** 而不是 1（v1 的 tween 把透明度拉到 1，是“发光过大”的真正原因）；线路 glow 18px/0.13 → **12px/0.085**。
3. **缩放控件 + 播放期可缩放**：右侧常驻 ＋/－/复位/比例尺。播放期间禁用的是拖拽、滚轮、双击、键盘等手势，按钮缩放始终可用；缩放结束会重算站名标签避让。
4. **多线路 + 城际特殊标识**：
   - 默认株洲 4 条线：1 号线（红）、2 号线（蓝）、3 号线（绿）、长株潭城际（紫，虚线描边）；
   - 城际线：**虚线**线路 + 城际徽章（圆角矩形「城际」）+ 站名标签「城际」胶囊；仅城际服务的站用**方形站标**；
   - 线路多选：右上「线路」面板勾选参与播放的线路（至少保留一条），未勾选的线路不参与动画与统计；
   - 顶部徽章、日期、区间、数据面板随当前播放线路实时切换，末条线路决定终态。
5. **前后端可用、可交付**：见「方式 B」。服务端零依赖（仅 `node:http/fs/path/url`），带 plan 严格校验（含跨线换乘站坐标一致性）、404/403 防目录穿越、512KB 请求体上限、原子写盘与损坏自恢复。

## 四、已知限制（如实说明）

1. **城际铁路用的是「长株潭城际」名义的虚构线网**：站名与坐标取自株洲/湘潭真实地点，但线路走向与开通日期为演示数据，不对应现实规划。
2. **高德瓦片接口本身不校验 Key**：因此 Key 无效时仍可出图（这是有意的），失效判定后才会静默回退；`keyStatus` 与设置面板文案会如实显示「校验通过 / 无效已回退 / 网络不可达保留瓦片」。
3. **矢量底图（无 Key 或 Key 无效时的第二层）**在跨城市大跨度跳转时，MapLibre 内部 worker 会打印 1 条 `Expected value to be of type number, but found null instead.`（第三方样式解析 warning，非 error）；栅格与高德底图无任何告警。
4. **断网时**不请求远程瓦片，直接用本地浅灰画布（版权标注「底图：本地浅灰画布（离线）」），因此断网场景零请求、零 console 报错。
5. **窄屏（≤720px）**站名过于密集时会隐藏次要站名（终端站/换乘站始终保留），这是刻意的防重叠策略；放大或复位视野后会重新参与避让。
6. **服务端**无鉴权、无 TLS，默认仅监听 `127.0.0.1`；单实例文件存储、后写者胜，适合本机/内网演示。
7. 交付文件内保留了 `window.__METRO__` 调试接口（只读快照 + 少量测试用方法），便于后续维护与自动化验收；不影响正常使用。
